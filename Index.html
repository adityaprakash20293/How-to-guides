Configure a new parking endpoint
Use-case example
When they are not executing missions or charging, it is important that your AMRs can park out of the way of each other; and out of the way of other facility operations.
Use this guide to update the OTTO Fleet Manager map with new parking endpoints; automating parking when AMRs are left without assigned work.
Create endpoint(s)
Waypoint and Parking Endpoints are used for workstations, queues, parking spots, or other types of goals that don't require specific docking instructions.
It is important that waypoints are placed in a position that a robot can easily navigate to. Your robot's Navigation Specification includes information about the space required for autonomous parking.
Parking Endpoints should always be positioned out of trafficways and operating areas.
  1. In OTTO Fleet Manager, ensure the user mode is set to Administrator.
  2. In OTTO Fleet Manager, select Configure > Facility > Edit (or click the editing map thumbnail).
  3. From the Top Bar menu of the map editor, select Endpoints ().
    1. Select Parking Endpoint.
      Note
      If the Parking Endpoint template is not present in the Endpoints list, it can be added from the Endpoint Library.
      From the Top Bar menu of the map editor, select Endpoints () > Library ().
      In the Endpoint Library panel, select Add Templates () > Add from defaults.
      From the Add Templates menu, select the Parking Endpoint and select Add Templates.
    2. Click on the map to place the new endpoint.
    3. Use the dial to move or rotate the new endpoint.
  4. Edit the endpoint details as necessary using the Properties panel (Right Drawer):
    1. Enter a distinct Name for the endpoint.
    2. Edit the endpoint details and placement as required:
      Parameter
      Recommended Value
      x, y, Orientation (°)
      <Facility dependent>
      Waypoint Type
      Parking
  5. Select Done.
  6. To save the changes to the map, select Save ().
Add endpoints to the Idle Parking endpoint group
An Endpoint Group is a collection of Endpoints that can be used interchangeably to perform the same Task.
Three system endpoint group types—Idle Parking, Chargers, and Overflow Parking—are provided in Fleet Manager to better organize fleet traffic and assist in keeping your facility clutter-free.
The Idle Parking endpoint group identifies for OTTO Fleet Manager which endpoints can be used for parking idle robots.
  1. In OTTO Fleet Manager, ensure the user mode is set to Administrator.
  2. In OTTO Fleet Manager, select Configure > Facility > Edit (or click the editing map thumbnail).
  3. In the Left Bar menu, select Endpoints () > Endpoint Groups > Idle Parking.
  4. Select the Endpoints to include in the Endpoint Group.
    1. Select .
    2. Select all associated endpoints.
  5. Select Done.
  6. To save the changes to the map, select Save ().
(Optional) Configure robot team(s)
It may be important for your fleet to separate parking endpoints by robot, by robot model, or by some other grouping.
Assigning parking endpoints to specific teams limits which robots are allowed to park at each endpoint.
  1. In OTTO Fleet Manager, ensure the user mode is set to Administrator.
  2. Select Monitor > Fleet > Teams.
  3. Assign your endpoints to a robot team:
    1. Select an existing team or New.
    2. To add a robot to the Team, select Add for the desired robot.
    3. To edit the Endpoints assigned to the Team, select Manage Endpoints and add or remove Endpoints.
    4. Select Done.
    5. Select Save (or Create if creating a New Team)
